# Wiener Filtering for Speech Enhancement

## ELEC5305 Project

This project investigates the use of Wiener filtering for speech enhancement. The aim is to reduce background noise in a speech recording while preserving the clarity of the speech signal.

The project will be implemented in MATLAB. The original and filtered speech will be compared using audio playback, waveforms and spectrograms.
